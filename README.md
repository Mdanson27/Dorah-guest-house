## Current build

- Brand palette extracted from the supplied Dorah Haven logo.
- Premium animated logo-inspired loader.
- Responsive hero, availability enquiry strip, rooms, amenities, gallery, FAQ, reviews placeholder and contact CTA.
- Direct WhatsApp and telephone actions using **+256 750 791591**.
- House illustrations are temporary placeholders for the motel's real photography.
- Static architecture suitable for GitHub Pages.

## Replace placeholder imagery

The current files are in `assets/placeholders/`:

- `house-1.svg` — hero / main property
- `house-2.svg` — room placeholder
- `house-3.svg` — evening / room placeholder
- `house-4.svg` — exterior placeholder
- `house-5.svg` — room/gallery placeholder
- `house-6.svg` — amenities placeholder

When real images arrive, they can be added under `assets/images/` and the relevant image paths in `index.html` and `css/styles.css` can be replaced.

## Run locally

Open `index.html`, or run a simple local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
